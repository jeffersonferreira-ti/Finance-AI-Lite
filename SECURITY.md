# Security

## Credenciais

Nunca versione:

- `GEMINI_API_KEY`
- IDs privados de planilhas
- tokens de acesso
- dumps contendo dados financeiros pessoais

O Finance AI Lite espera as credenciais em **Script Properties**.

## Dados pessoais

O repositório deve conter apenas código e documentação.

Não publique cópias reais das abas:

- Transacoes
- Contas
- Saldos
- Faturas
- Assinaturas
- Metas
- ConversasIA

Caso utilize screenshots, remova ou anonimize valores e instituições que não queira expor publicamente.

## Web App

Para uso pessoal, configure o acesso da implantação no nível mais restrito compatível com seu cenário.

## Reporte de vulnerabilidades

Este projeto é atualmente um projeto pessoal/educacional. Não publique credenciais em issues.
