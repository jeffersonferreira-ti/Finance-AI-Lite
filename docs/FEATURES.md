## Contas

O saldo calculado considera:

```text
Saldo inicial
+ Receitas
- Despesas imediatas
- Pagamentos de fatura
+ Transferências recebidas
- Transferências enviadas
```

Compras no crédito não reduzem o caixa imediatamente.
